# 🚀 Estudos de Javascript para QA

Repositório destinado aos exercícios de lógica de programação desenvolvidos durante o curso de **Javascript para QAs** do Fernando Papito. O objetivo principal foi consolidar a base técnica para iniciar em Automação de Testes com Cypress

## 🛠️ O que foi desenvolvido
O foco deste projeto não foi o framework front-end, mas sim a **Lógica de Javascript** aplicada a ele:
* **Manipulação de Listas:** Uso de Arrays para renderizar personagens na tela.
* **Condicionais:** Lógica para exibir elementos baseados em regras de negócio.
* **Consumo de Dados:** Estruturação de objetos JSON simulando uma API.
* **CSS:** Ajustes pontuais de estilização para compor o cenário de testes.

## 🌌 Sobre o Projeto Star Wars
Utilizei uma estrutura base em Vue.js (fornecida no curso) para aplicar na prática os conceitos de:
* Looping de dados
* Interação com elementos da interface
* Debug e análise de comportamento do código no navegador

## 💡 Por que isso é importante para QA?
Este projeto serviu para treinar o olhar técnico sobre como o **Javascript** controla a interface, habilidade essencial para criar seletores e asserções precisas em testes automatizados.
